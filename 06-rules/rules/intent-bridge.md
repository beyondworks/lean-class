# Intent Bridge 운영 규칙

> 사용자의 자연어 요청을 내부적으로 AgentSpec v1으로 변환한 뒤 실행.
> AgentSpec 자체는 사용자가 명시적으로 요청하지 않는 한 노출하지 않음.

## 핵심 동작

- 사용자는 자연어로 자유롭게 말할 수 있어야 함
- 구현 전 내부적으로 AgentSpec v1 구성
- 안전·정확성에 필수일 때만 확인 질문. 그 외엔 합리적 추정 + 진행
- 모든 확인 질문은 평이한 언어 + 짧은 선택형
- 기술 용어 무거운 질문 금지

## 표준 워크플로

1. 사용 가능한 MCP 도구로 프로젝트 컨텍스트 읽기
2. 내부 AgentSpec v1 구성
3. 구현 전 AgentSpec 검증
4. 핵심 정보 누락 시 평이한 언어로 최대 2개 질문
5. 저위험 + 합리적 추정 가능 → 추정 제시 후 진행
6. AgentSpec 저장
7. 가장 작은 출하 가능 버전(MVS)부터 구현
8. 파괴적/고위험 행위만 확인 후 실행
9. 변경 사항 한 줄 요약으로 종료

## Metric Lock (성공 지표 고정)

- 모든 작업은 측정 가능한 성공 지표 포함
- 사용자 미제시 시: "Proposed Metric (editable)" 자동 생성
- 자명한 변경은 기본 수용 규칙 사용:
  "요청 변경 구현, 무관 영역 미파손, lint/test 통과(가능한 경우)"

## 확인 질문 작성 규칙

- 기술 용어 대신 일상어
- 선택지 2~3개 최대
- 적절한 경우 "추천해줘" 옵션 포함
- 한 질문에 한 결정만

## 안전

- 파괴적 명령(삭제·force push·DB 변경 등)은 사용자 확인 후
- 무관한 파일 수정 금지
- 수용 기준 검증 없이 성공 선언 금지
