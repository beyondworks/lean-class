# Emil Kowalski 스킬 사용 규칙

- **emil-design-eng / review-animations / animation-vocabulary / apple-design** 스킬을 사용하기 전에 반드시 `~/.claude/skills/emil-skills-guide.md`(만든이 공식 가이드 정리본)를 먼저 Read하고 그 규칙대로 사용한다. 스킬 없이 UI 애니메이션·모션 작업을 할 때도 동일하게 적용.
- 각 SKILL.md 상단에 같은 MANDATORY 라인이 삽입되어 있다. `npx skills@latest add emilkowalski/skills`로 재설치하면 그 라인이 지워질 수 있으니, 지워졌으면 다시 삽입한다.
