# 자가 학습 루프

> 같은 실수를 두 번 하지 않기 위한 누적 학습 시스템.
> 다중 도메인(영상·커머스·SaaS·자동화)을 동시에 운영할 때, 한 도메인에서 배운 교훈이 다른 도메인에서도 적용되도록 강제.

## 저장 위치

- **글로벌 lessons**: `~/.claude/lessons.md` — 도메인 무관 공통 패턴
- **프로젝트 lessons**: 프로젝트 MEMORY.md의 "Lessons" 섹션 — 프로젝트 고유 패턴
- 글로벌과 프로젝트가 겹치면 글로벌이 우선

## 자동 기록 트리거 (즉시 추가)

다음 신호 중 하나라도 발생하면 즉시 lessons.md에 한 줄 추가:

- **명시적 교정** — "그건 틀렸어", "이렇게 해야 해", "다시 봐봐"
- **재시도 요청** — "다시 해줘", "이 부분 다시"
- **결과 거부** — "이건 별로야", "다른 방법은?"
- **사용자 보강** — "근데 이것도 빼먹었어"
- **자가 발견** — 디버깅 중 회피 가능했던 실수를 본인이 인지했을 때

## 기록 형식

한 줄, 다음 형식 고정:

```
YYYY-MM-DD / 도메인 / 실수 패턴 → 방지 규칙
```

도메인 예: `UI`, `보안`, `영상`, `커머스광고`, `SaaS`, `MCP`, `자동화`, `도구추천`, `검증`, `소통`

## 예시 라인

```
2026-05-18 / UI / 빌드 통과만으로 "완료" 선언 → dev 서버 + 브라우저 시각 확인 후 선언
2026-05-17 / 영상분석 / macOS TempItems 경로 권한 막힘 → 접근 가능 위치(~/Desktop, ~/Movies)로 이동 후 분석
2026-05-14 / 도구추천 / 저자 토큰 절감 주장 그대로 인용 → Claude Code 환경 베이스라인 검증 후 NET 절감 재계산
2026-05-10 / 검증 / 시스템 reminder를 사용자 입력으로 오인 → 자동 알림과 사용자 메시지 구분
```

## 세션 시작 시 활용

1. 세션 시작 직후 lessons.md 먼저 읽기 (MEMORY.md와 함께)
2. 현재 작업 도메인 매칭되는 라인 식별
3. 작업 진행 시 해당 lesson을 명시적으로 적용 — 필요 시 짧게 언급("이전 lesson에 따라 X 먼저 확인")

## 누적 관리

- **형식 엄수** — 항상 한 줄. 장문 회고는 MEMORY.md에 별도 작성
- **중복 통합** — 같은 패턴이 두 줄 이상이면 합치고 `[x2]` `[x3]` 표기 (반복 = 진짜 약점)
- **분기 정리** — 3개월마다 상위 20개로 압축. 더 이상 발생 안 하는 패턴은 `lessons-archive/YYYY-Q*.md`로 이동
- **모델 세대 감사 (2026-08-05 신설)** — lesson은 두 종류다: ①모델 약점 대응(실행 하네스형 — 새 모델 전환 시 만료 후보) ②우리 팀 판단 기준·검증된 외부 사실(영구). 새 모델 전환 시 ①을 "이거 왜 넣었더라" 기준으로 감사해 삭제한다. 기억 안 나면 삭제, 지금 모델이 안 하는 실수 대응이면 삭제, 판단 기준·사실이면 유지
- **태그 활용** — 반복 발생 시 라인 끝에 `[REPEATED]`, 시스템적 약점 확정되면 `[SYSTEMIC]` 추가 → 해당 라인은 rules/로 승격 검토

## rules/ 승격 기준

lesson이 다음 조건을 모두 만족하면 rules/ 신규 파일 또는 기존 rules/에 정식 편입:

- 같은 패턴이 3회 이상 반복 (`[x3]` 이상)
- 도메인 무관하게 적용되는 일반 규칙
- 한 줄로 끝나지 않고 부연 설명·예시가 필요한 경우

## 안티 패턴 (lessons.md에 쓰지 말 것)

- "다음부터는 잘하겠습니다" 같은 모호한 다짐 — 반드시 구체적 방지 규칙
- 작업 결과/회고 — 그건 MEMORY.md
- 코드 스니펫·긴 분석 — lessons는 한 줄
