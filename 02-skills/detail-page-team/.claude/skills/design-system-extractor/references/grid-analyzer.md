# Grid Analyzer

그리드 시스템 분석 및 토큰화 규칙

## 그리드 구성 요소

```
│← Margin →│←────────── Container ──────────→│← Margin →│
│          │                                  │          │
│          │ Col │ Gutter │ Col │ Gutter │ Col│          │
│          │  1  │        │  2  │        │  3 │          │
```

### 구성 요소 정의
- **Margin**: 화면 가장자리 여백
- **Container**: 콘텐츠 최대 너비
- **Column**: 콘텐츠 배치 영역
- **Gutter**: 컬럼 사이 간격

## 플랫폼별 표준

### 쿠팡
```
Container: 860px
Columns: 자유 (주로 1-2 컬럼)
Gutter: 20-24px
Margin: auto (중앙 정렬)
```

### 스마트스토어
```
Container: 860px
Columns: 자유
Gutter: 20-24px
Margin: auto
```

### 마켓컬리
```
Container: 1010px
Columns: 주로 1컬럼, 가끔 2-3
Gutter: 24-32px
Margin: auto
```

### 카페24 (자사몰)
```
Container: 1200px (반응형)
Columns: 12컬럼 그리드
Gutter: 24-32px
Margin: 반응형
```

## 분석 방법

### 1. Container 너비 측정

```
1. 메인 콘텐츠 영역 너비 측정
2. 일반적인 값과 비교:
   - 860px: 쿠팡/스마트스토어
   - 960px: 작은 컨테이너
   - 1010px: 마켓컬리
   - 1140px: Bootstrap
   - 1200px: 일반적
   - 1280px: Material Design
```

### 2. 컬럼 수 추정

```
요소 배치 패턴 관찰:
- 1개 나란히 → 1컬럼 (100%)
- 2개 나란히 → 2컬럼 (50/50 또는 비대칭)
- 3개 나란히 → 3컬럼 (33.3%)
- 4개 나란히 → 4컬럼 (25%)

12컬럼 시스템 매핑:
- 3개 카드 → 각 4컬럼
- 4개 카드 → 각 3컬럼
- 사이드바 → 3+9 또는 4+8
```

### 3. Gutter 측정

```
요소 사이 간격 측정:
- 16px: 촘촘한 레이아웃
- 20px: Bootstrap 기본
- 24px: 일반적
- 32px: 여유로운 레이아웃
- 40px+: 와이드 레이아웃
```

### 4. 반응형 브레이크포인트

```
일반적인 값:
xs: 0-639px      (모바일)
sm: 640-767px    (소형 태블릿)
md: 768-1023px   (태블릿)
lg: 1024-1279px  (데스크톱)
xl: 1280px+      (대형 데스크톱)
```

## 이커머스 상세페이지 특수 규칙

### 단일 컬럼 우선
```
상세페이지는 대부분 단일 컬럼 스크롤 구조:
- 최대 너비 고정 (860px, 1010px)
- 중앙 정렬
- 이미지 100% 너비
- 텍스트 좌측 정렬
```

### 섹션 구분
```
섹션 간 간격: 40-80px
섹션 내 요소 간격: 16-32px
```

### 카드 그리드 (상품 추천 등)
```
2컬럼: 50% + 50%, gap 16-24px
3컬럼: 33.3%, gap 16-24px
모바일: 1컬럼으로 스택
```

## 분석 리포트 형식

```markdown
## 그리드 시스템 분석

### Container
- 최대 너비: 860px
- 정렬: 중앙

### 레이아웃 패턴
- 메인: 단일 컬럼
- 카드 그리드: 2-3 컬럼

### 간격
- 섹션 간: 48px
- 요소 간: 24px

### 반응형
- Desktop: 860px 고정
- Mobile: 100% + padding 16px
```

## 검증

### 일관성 확인
```
- 모든 섹션 동일 너비?
- 간격 패턴 규칙적?
- 반응형 깨짐 없음?
```

### 가독성 확인
```
- 줄 길이 적절? (최대 75자 권장)
- 여백 충분?
- 모바일 터치 영역 충분?
```
