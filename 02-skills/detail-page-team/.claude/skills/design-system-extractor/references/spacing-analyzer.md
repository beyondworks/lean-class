# Spacing Analyzer

간격 시스템 분석 및 토큰화 규칙

## 기본 원칙

### 8px 그리드 시스템
```
모든 간격은 8px의 배수:
4, 8, 12, 16, 24, 32, 40, 48, 64, 80, 96...

예외: 4px (미세 조정용)
```

### 4px 그리드 시스템 (대안)
```
더 촘촘한 조정 필요 시:
4, 8, 12, 16, 20, 24, 28, 32...
```

## 수집 대상

### Padding (내부 여백)
```css
padding: 16px;
padding: 24px 32px;
padding-top: 40px;
```

### Margin (외부 여백)
```css
margin: 24px;
margin-bottom: 48px;
margin: 0 auto;
```

### Gap (Flexbox/Grid)
```css
gap: 24px;
row-gap: 16px;
column-gap: 24px;
```

## 역할별 분류

### 섹션 간격 (Section Spacing)
```
대형: 64-96px (주요 섹션 분리)
중형: 40-48px (섹션 내 블록 분리)
소형: 24-32px (관련 요소 그룹)
```

### 요소 간격 (Element Spacing)
```
대형: 24-32px (카드 사이, 목록 항목)
중형: 16-20px (텍스트 블록, 버튼 그룹)
소형: 8-12px (밀접한 관련 요소)
미세: 4px (아이콘-텍스트, 인라인 요소)
```

### 컴포넌트 패딩 (Component Padding)
```
버튼: 12-16px (vertical), 24-32px (horizontal)
카드: 16-24px
입력 필드: 12-16px
컨테이너: 16-40px (반응형)
```

## 이커머스 상세페이지 패턴

### 섹션 간격
```
히어로 → 다음 섹션: 48-64px
일반 섹션 사이: 40-48px
관련 섹션 그룹: 24-32px
```

### 제목-본문 간격
```
H1 → 본문: 24-32px
H2 → 본문: 16-24px
H3 → 본문: 12-16px
```

### 목록/카드 간격
```
카드 사이: 16-24px
목록 항목 사이: 12-16px
체크리스트 항목: 8-12px
```

### 버튼/CTA 간격
```
버튼 그룹 사이: 12-16px
버튼 위아래 여백: 24-32px
```

## 분석 리포트 형식

```markdown
## 간격 시스템 분석

### 기본 단위
- Base: 8px

### 주요 간격 값
| 역할 | 값 | 용도 |
|------|-----|------|
| 섹션 간격 | 48px | 주요 블록 분리 |
| 요소 간격 | 24px | 카드, 목록 |
| 미세 간격 | 8px | 관련 요소 |

### 패턴
- 8px 배수 사용
- 섹션 간: 48px 일관
- 요소 간: 16-24px 범위
```

### 시각적 균형
```

```

## 정규화 규칙

### 실제 값 → 표준 스케일
```javascript
// 가장 가까운 8px 배수로 반올림
13px → 12px (3)
17px → 16px (4)
22px → 24px (6)
35px → 32px (8)
```

### 예외 처리
```
- 4px: 허용 (미세 조정)
- 홀수 값: 가장 가까운 짝수로
- 100px+: 그대로 사용
```
