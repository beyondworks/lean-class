# SVG·화면 그림 만드는 법 (복사해 쓰는 조각)

아래 조각을 복사해 시작하면 된다.

## 1. 글자는 상자 중앙 기준으로

```python
def text(self, x, y, s, size=15, weight=400, fill=INK, anchor="start", font=SANS, mid=False):
    # mid=True: y를 글자의 세로 중앙으로 본다. 0.38em은 한글 기준 세로 중앙이다.
    dy = ' dy="0.38em"' if mid else ""
    self.a(f'<text x="{x}" y="{y}"{dy} font-size="{size}" font-weight="{weight}" fill="{fill}" '
           f'text-anchor="{anchor}" font-family="{font}" xml:space="preserve">{escape(s)}</text>')
```

- 상자(알약, 버튼, 배지, 카드 제목, 표 행) 안 글자는 `y = 상자 y + 높이/2`, `mid=True`.
- 여러 줄은 줄마다 `y = 중앙 + (i - (n-1)/2) * 줄간격`.
- 하지 말 것: `y + 높이/2 + 5` 같은 숫자 보정. 글꼴과 렌더러가 바뀌면 3~4px 어긋난다.

## 2. 2026년 감각의 기본 값

| 요소 | 값 |
|---|---|
| 글꼴 | `Pretendard, Apple SD Gothic Neo, Noto Sans KR, sans-serif` |
| 경계 | 1px `#e4e4e7`, 반경 16~20 |
| 면 | 연한 색(예: 파랑 `#eff4ff`, 초록 `#effaf2`, 호박 `#fff7e8`) |
| 강조색 | 하나(파랑 `#2563eb` 등). 의미색은 연한 배경에 진한 글자 |
| 아이콘 | 선 아이콘 1.6~2px, 둥근 끝 |
| 화살표 | 선 + 열린 쉐브론(가는 선) |
| 글자 | 제목 20~22 / 본문 15~16 / 캡션 13. 도면 폭 820 기준 |

## 3. 설명서식 그림: 화면 + 붉은 표시

사용자 조작 단계(앱 열기, 파일 끌어다 놓기, 허용 누르기, 결과 확인)를 설명할 때, 도식 대신 화면을 재현하고 붉은 표시를 얹는다. 실제 캡처가 있으면 캡처 위에 같은 방식으로 얹는다.

- 붉은 네모: 흰 후광(stroke 7) 위에 붉은 3px 선, `fill-opacity 0.07`
- 번호 배지: 반지름 16, 붉은 바탕, 흰 테두리 2.5, 숫자 18 굵게(중앙 배치)
- 화살표: 흰 후광 8px 위에 붉은 3.5px 선 + 삼각 머리
- 설명 알약: 흰 바탕 + 붉은 2px 테두리 + 붉은 굵은 글자 16~17px, 높이 `글자크기 + 18`
- 번호는 배지와 설명을 같이 쓴다(①, ②). 번호표는 창 밖으로 잘리지 않는 곳에 둔다.
- 화면 재현은 사용자가 가진 실제 화면을 기준으로 한다(상단 아이콘, 사이드바 항목, 버튼 이름). 추정으로 그린 부분은 "예시 화면" 문구로 표시한다.
- 필요한 부분만 확대해서 보여 준다. 창 전체를 그대로 그리지 않는다.

## 4. 자주 나온 결함과 처방

| 결함 | 처방 |
|---|---|
| 카드 사이 간격 0 | 카드 폭과 간격을 합쳐 도면 폭에서 빼 계산한다(예: 폭 296 + 간격 24) |
| 번호표가 창 위로 잘림 | 번호표를 상자 안쪽 모서리나 아래쪽으로 옮긴다 |
| 화살표가 글자를 가림 | 화살표 끝을 글자가 없는 테두리로 끝낸다 |
| 사이드바 항목이 창 밖으로 넘침 | 창 높이를 늘리거나 항목 수를 줄인 compact 모드를 쓴다 |
| 이름과 시각이 겹침 | Finder처럼 이름을 가운데 줄임(…)으로 줄인다 |
| 설명 알약이 창 테두리에 닿음 | 창 높이를 키워 아래 여백을 둔다 |
| 상자 안 글자가 테두리에 붙음 | 상자 좌우 여백 16px 이상 |
