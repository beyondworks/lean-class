# Human-Like Description Rules

분석 결과를 사람이 눈으로 본 듯한 수준으로 묘사하는 규칙

## 핵심 원칙

### 코드가 아닌 디자이너의 눈으로

```
❌ 나쁜 예 (코드 중심):
"primary color: #FF6B35, font-size: 48px, margin-bottom: 24px"

✅ 좋은 예 (사람 눈 중심):
"선명하면서도 따뜻한 오렌지가 브랜드를 대표함.
제목이 크고 임팩트 있어서 시선을 확 끔.
섹션 간 여백이 넉넉해서 시원하고 프리미엄한 느낌."
```

## 묘사 가이드

### 색상 묘사

#### 느낌으로 표현

| 코드 값 | 나쁜 묘사 | 좋은 묘사 |
|---------|----------|----------|
| #FF6B35 | "오렌지색" | "따뜻하면서도 활기찬 오렌지. 친근하지만 가벼워 보이지 않음." |
| #3B82F6 | "파란색" | "선명하고 신뢰감 주는 파랑. 테크 기업에서 자주 보는 톤." |
| #171717 | "검정색" | "거의 검정에 가까운 진한 색. 가독성 좋고 무거운 느낌." |
| #FAFAFA | "회색" | "거의 흰색에 가까운 밝은 배경. 눈이 편하고 깨끗한 인상." |

#### 색상 관계 묘사

```markdown
## 색상 조화

Primary와 Secondary가 그라데이션으로 자연스럽게 연결됨.
오렌지에서 레드로 흐르는 색상이 따뜻하고 에너지 넘치는 느낌.
흰 배경과 대비되어 눈에 잘 띄지만 피로하지 않음.
```

### 타이포그래피 묘사

#### 폰트 성격 표현

| 코드 | 나쁜 묘사 | 좋은 묘사 |
|------|----------|----------|
| Inter 700 | "Bold 폰트" | "두껍고 단단한 느낌. 신뢰감과 전문성을 전달." |
| line-height: 1.1 | "줄간격 1.1" | "글자가 꽉 차 있어서 덩어리감 있음. 임팩트 있는 헤드라인." |
| letter-spacing: -0.02em | "자간 -0.02em" | "글자가 살짝 모여 있어서 타이트하고 현대적인 느낌." |

#### 계층 구조 묘사

```markdown
## 타이포그래피 계층

제목이 매우 크고 굵어서 페이지의 주인공.
소제목은 제목보다 확 작지만 여전히 눈에 띔.
본문은 편하게 읽히는 크기로, 줄간격이 넉넉.
전체적으로 계층이 명확해서 스캔하기 좋음.
```

### 여백/레이아웃 묘사

#### 간격 느낌 표현

| 수치 | 나쁜 묘사 | 좋은 묘사 |
|------|----------|----------|
| 80px | "80픽셀 마진" | "섹션 사이가 넉넉해서 콘텐츠가 숨 쉴 공간이 있음." |
| 24px | "24픽셀 갭" | "카드 사이 여백이 적당해서 연관성이 느껴지면서도 답답하지 않음." |
| 16px | "16픽셀 패딩" | "카드 내부가 약간 촘촘. 콤팩트하지만 정보가 잘 정리됨." |

#### 레이아웃 느낌 표현

```markdown
## 레이아웃 인상

전체적으로 여유로운 레이아웃.
Apple 사이트처럼 콘텐츠보다 여백이 많은 스타일.
시선이 자연스럽게 위에서 아래로 흐름.
모바일에서도 답답하지 않게 잘 정리됨.
```

### 컴포넌트 묘사

#### 버튼 묘사

```markdown
## 버튼 스타일

둥글둥글한 pill 형태로 부드럽고 친근한 느낌.
오렌지 배경에 흰 텍스트로 눈에 확 띔.
호버하면 살짝 어두워지면서 누르고 싶은 느낌.
그림자가 없어서 플랫하고 현대적.
```

#### 카드 묘사

```markdown
## 카드 스타일

모서리가 부드럽게 둥글어서 딱딱하지 않음.
은은한 그림자가 살짝 떠있는 느낌을 줌.
내부 여백이 넉넉해서 콘텐츠가 여유롭게 배치됨.
이미지와 텍스트의 비율이 균형 잡힘.
```

## 묘사 팁

### DO (이렇게 하세요)

- ✅ 구체적인 감각 표현 사용
- ✅ 비교를 통한 설명 ("~처럼", "~와 비슷")
- ✅ 용도와 효과 연결
- ✅ 긍정/부정 느낌 표현
- ✅ 전체 맥락에서 설명

### DON'T (이렇게 하지 마세요)

- ❌ 수치만 나열
- ❌ 기술적 용어만 사용
- ❌ 맥락 없는 단순 설명
- ❌ 주관 배제한 건조한 묘사

## 좋은 묘사의 예시

```markdown
## Jeton 분석 예시

### 브랜드 인상
"유럽의 핀테크 스타트업 느낌. 
뱅킹 앱치고는 딱딱하지 않고 친근함.
오렌지 그라데이션이 '간편하고 빠른 송금'이라는 
서비스 특성과 잘 어울림."

### 색상 느낌
"메인 오렌지가 선명하지만 눈에 피로하지 않은 톤.
흰 배경에서 CTA 버튼이 확 튀어서 누르고 싶게 만듦.
그라데이션이 자연스러워서 저렴해 보이지 않음."

### 타이포 느낌
"제목이 Extra Bold로 무게감 있음.
'One app for all needs' 같은 카피가 
큰 폰트로 시원하게 들어와서 기억에 남음.
본문은 가독성 좋게 적당한 크기."

### 레이아웃 느낌
"여백이 Apple 수준으로 넉넉.
각 섹션이 충분히 숨 쉬고 있어서 프리미엄해 보임.
스크롤하면서 자연스럽게 서비스를 이해하게 됨."
```

## 체크리스트

작성 완료 전 확인:

- [ ] 코드 값 대신 느낌으로 표현했는가?
- [ ] 브랜드 인상이 명확한가?
- [ ] 비전문가도 이해할 수 있는가?
- [ ] 구체적인 예시가 포함되었는가?
- [ ] 전체적인 맥락이 연결되는가?
