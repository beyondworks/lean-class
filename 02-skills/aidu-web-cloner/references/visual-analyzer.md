# Visual Analyzer

스크린샷을 사람이 눈으로 본 듯한 수준으로 분석

## 분석 원칙

### 디자이너의 눈으로 보기

```
❌ 코드 중심:
"font-size: 48px, font-weight: 700, color: #171717"

✅ 사람 눈 중심:
"제목이 크고 임팩트 있음. 굵은 서체로 시선을 끔.
거의 검정에 가까운 진한 색으로 가독성 좋음."
```

## 분석 순서

### 1단계: 전체 인상 파악 (First Impression)

스크린샷을 5초간 보고 느낀 첫인상 기록:

```markdown
## 첫인상

- 전체적인 분위기: [밝은/어두운/화려한/미니멀/...]
- 브랜드 느낌: [신뢰/활기/고급/친근/전문적/...]
- 주요 색상 톤: [따뜻한/차가운/중립적/...]
- 여백 느낌: [넉넉한/촘촘한/균형잡힌/...]
- 타겟 사용자 추정: [젊은층/전문가/일반인/...]
```

### 2단계: 색상 분석 (Color Analysis)

#### 주요 색상 식별

```markdown
## 색상 분석

### Primary Color
- 위치: [어디에 사용되는지]
- 느낌: [선명한/부드러운/차분한/...]
- 용도: [CTA/강조/브랜드/...]

### Secondary Color
- 위치: [어디에 사용되는지]
- 느낌: [...]
- Primary와의 관계: [보색/유사색/...]

### Background
- 메인 배경: [흰색/밝은 회색/어두운/...]
- 섹션 구분: [색상으로 구분/여백으로 구분/...]

### Text Colors
- 제목: [거의 검정/진한 회색/...]
- 본문: [...]
- 보조 텍스트: [...]
```

#### 색상 느낌 묘사 예시

| 느낌 | 묘사 |
|------|------|
| 선명한 파랑 | "눈에 확 들어오는 강렬한 파랑. 신뢰와 전문성." |
| 부드러운 오렌지 | "따뜻하지만 부담스럽지 않은 톤. 친근하고 활기참." |
| 깊은 네이비 | "고급스럽고 안정적인 느낌. 금융/비즈니스 적합." |
| 연한 회색 | "눈에 피로감 없이 오래 볼 수 있는 배경." |

### 3단계: 타이포그래피 분석 (Typography Analysis)

#### 폰트 특성 파악

```markdown
## 타이포그래피 분석

### 폰트 성격
- 분류: [Sans-serif/Serif/...]
- 세부 분류: [Geometric/Humanist/Modern/...]
- 느낌: [모던/클래식/플레이풀/...]

### 제목 스타일
- 굵기 느낌: [매우 굵음/적당히 굵음/가벼움]
- 크기 느낌: [매우 큼/적당함/작음]
- 줄간격: [타이트/여유로움]
- 인상: [임팩트/우아함/친근함]

### 본문 스타일
- 가독성: [매우 좋음/보통/...]
- 줄간격: [넉넉/적당/촘촘]
- 단락 간격: [여유로움/적당/빽빽함]

### 크기 대비
- 제목 vs 본문: [대비 큼/적당/작음]
- 계층 구조: [명확함/불명확]
```

### 4단계: 레이아웃 분석 (Layout Analysis)

#### 구조 파악

```markdown
## 레이아웃 분석

### 전체 구조
- 섹션 수: [대략 몇 개]
- 섹션 구분 방식: [배경색/여백/구분선/...]
- 정렬: [중앙/좌측/혼합]

### 각 섹션 특징

#### 히어로 섹션
- 높이: [전체 화면/80%/절반/...]
- 구성: [텍스트만/텍스트+이미지/...]
- 배치: [중앙/좌측 텍스트+우측 이미지/...]
- 특수 효과: [그라데이션/이미지 오버레이/...]

#### 콘텐츠 섹션
- 컬럼 구조: [1컬럼/2컬럼/3컬럼/카드 그리드]
- 요소 정렬: [중앙/좌측/...]
- 여백 느낌: [넉넉/적당/촘촘]

#### 푸터
- 컬럼 수: [...]
- 정보량: [많음/적당/미니멀]
```

### 5단계: 컴포넌트 식별 (Component Identification)

#### 반복 패턴 찾기

```markdown
## 컴포넌트 패턴

### 버튼
- 형태: [Pill/Rounded/Square]
- 크기 종류: [몇 가지]
- 스타일: [Filled/Outlined/Ghost]
- 특징: [그림자/호버 효과/아이콘 포함/...]

### 카드
- 형태: [그림자/보더/플랫]
- 모서리: [둥근/약간 둥근/각진]
- 내부 구성: [이미지+텍스트/아이콘+텍스트/...]

### 네비게이션
- 스타일: [투명/배경색/그림자]
- 로고 위치: [좌측/중앙]
- 메뉴 스타일: [...]
- CTA 버튼: [있음/없음]

### 입력 필드
- 스타일: [박스/언더라인/라운드]
- 라벨 위치: [위/안/좌측]

### 아이콘
- 스타일: [Line/Filled/Duo-tone]
- 크기: [일관됨/다양함]
```

## 분석 출력 템플릿

```markdown
# [사이트명] 디자인 분석

## 브랜드 인상 (5초 요약)
[첫인상을 2-3문장으로]

## 색상
### 느낌
[색상이 주는 전체적인 분위기]

### 팔레트
- Primary: [묘사] → 추정값: #______
- Secondary: [묘사] → 추정값: #______
- Background: [묘사]
- Text: [묘사]

## 타이포그래피
### 느낌
[폰트가 주는 인상]

### 특징
- 폰트 종류: [추정]
- 제목: [묘사]
- 본문: [묘사]

## 레이아웃
### 느낌
[전체 구조가 주는 인상]

### 구조
- 그리드: [추정 컬럼 수]
- 여백: [넉넉함 정도]
- 섹션 흐름: [자연스러움 정도]

## 주요 컴포넌트
[식별된 컴포넌트와 특징]

## 특수 요소
[애니메이션, 3D, 특별한 효과 등]
```

## 분석 팁

### 좋은 분석의 특징

```
✅ 구체적인 느낌 묘사
   "따뜻하면서도 전문적인 느낌의 오렌지"

✅ 비교를 통한 설명
   "Apple 사이트처럼 여백이 넉넉하고 미니멀"

✅ 용도와 연결
   "CTA에 사용되어 시선을 끄는 역할"

❌ 단순 나열
   "오렌지색 사용"

❌ 코드 값만
   "#FF6B35 색상"
```

### 불확실할 때

```
"정확히 [값]인지 확실하지 않지만,
느낌상 [추정]으로 보임.
코드 검증 필요."
```
