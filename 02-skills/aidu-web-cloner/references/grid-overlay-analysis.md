## 격자 유형

### 1. 기준선 격자 (Baseline Grid)

```
목적: 수직 리듬, 줄간격, 요소 높이 정렬 확인

┌─────────────────────────────────────┐
│─────────────────────────────────────│ 0px
│                                     │
│─────────────────────────────────────│ 8px
│  Heading Text                       │
│─────────────────────────────────────│ 16px
│                                     │
│─────────────────────────────────────│ 24px
│  Body text line 1                   │
│─────────────────────────────────────│ 32px
│  Body text line 2                   │
│─────────────────────────────────────│ 40px
│                                     │
└─────────────────────────────────────┘

확인 항목:
□ 텍스트 기준선이 격자에 정렬되는가?
□ 요소 높이가 격자 단위의 배수인가?
□ 수직 간격이 일관된 패턴인가?
```

### 2. 컬럼 격자 (Column Grid)

```
목적: 수평 레이아웃, 컬럼 구조, 정렬 확인

│←  margin  →│←───── container ─────→│← margin →│
│            │                        │          │
│    ┃▒▒▒┃   ┃▒▒▒┃   ┃▒▒▒┃   ┃▒▒▒┃   │          │
│    ┃   ┃   ┃   ┃   ┃   ┃   ┃   ┃   │          │
│    ┃col┃gut┃col┃gut┃col┃gut┃col┃   │          │
│    ┃ 1 ┃ter┃ 2 ┃ter┃ 3 ┃ter┃ 4 ┃   │          │
│    ┃   ┃   ┃   ┃   ┃   ┃   ┃   ┃   │          │
│    ┃▒▒▒┃   ┃▒▒▒┃   ┃▒▒▒┃   ┃▒▒▒┃   │          │
│            │                        │          │

구성 요소:
• Margin: 화면 가장자리 여백
• Container: 콘텐츠 최대 너비
• Column: 콘텐츠가 배치되는 영역
• Gutter: 컬럼 사이 간격
```

### 3. 측정 격자 (Measurement Grid)

```
목적: 정확한 픽셀 값 측정

    0    64   128  192  256  320  384  448  512
    │     │     │     │     │     │     │     │
  0 ┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─
    │ · · │ · · │ · · │ · · │ · · │ · · │ · · │
    │     │     │     │     │     │     │     │
 64 ┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─
    │ · · │ · · │ · · │ · · │ · · │ · · │ · · │
    │     │     │     │     │     │     │     │
128 ┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─

• 대격자: 64px 간격 (숫자 표시)
• 소격자: 8px 간격 (점선)
• 좌표계로 정확한 위치 측정 가능
```

## 스크립트 사용법

### 기본 사용

```bash
# 스크린샷 분석 (기본 설정)
python scripts/grid_analyzer.py screenshot.png

# 커스텀 설정
python scripts/grid_analyzer.py screenshot.png \
    --grid 8 \
    --columns 12 \
    --gutter 24 \
    --margin 32 \
    --container 1200 \
    --output ./analysis
```

### 출력 파일

```
grid_analysis/
├── 01_baseline_grid.png    # 8px 수평 기준선
├── 02_column_grid.png      # 12컬럼 레이아웃 격자
├── 03_measurement_grid.png # 픽셀 측정용 격자
├── 04_combined_grid.png    # 통합 격자
├── grid_tokens.json        # 추출된 토큰
└── analysis_report.json    # 전체 분석 결과
```

## 분석 워크플로우

### Step 1: 격자 설정 추정

```
스크린샷을 보고 초기 추정:

1. 컨테이너 너비
   → 콘텐츠 최대 너비 눈대중 측정
   → 일반적: 1200px, 1440px, 960px
   
2. 컬럼 수
   → 카드/요소 배치 패턴 관찰
   → 3개 나란히 → 12컬럼 (각 4컬럼)
   → 4개 나란히 → 12컬럼 (각 3컬럼)
   
3. 거터 크기
   → 요소 사이 간격
   → 일반적: 16px, 20px, 24px, 32px
   
4. 기준선 단위
   → 4px 또는 8px 기반
```

### Step 2: 격자 오버레이 생성

```bash
# 초기 추정값으로 격자 생성
python scripts/grid_analyzer.py screenshot.png \
    --columns 12 \
    --gutter 24 \
    --container 1200
```

### Step 3: 정렬 확인 및 조정

```
생성된 04_combined_grid.png 확인:

□ 요소가 컬럼 경계에 정렬되는가?
  → NO: 컬럼 수 또는 거터 조정
  
□ 컨테이너 너비가 맞는가?
  → NO: container 값 조정
  
□ 좌우 마진이 균등한가?
  → NO: margin 값 조정

반복하여 최적값 찾기
```

### Step 4: 토큰 추출

```json
// grid_tokens.json 예시
{
  "grid": {
    "columns": 12,
    "gutter": 24,
    "margin": 32,
    "container_width": 1200,
    "column_width": 74
  },
  "spacing": {
    "base_unit": 8,
    "semantic_mapping": {
      "xs": 4,
      "sm": 8,
      "md": 16,
      "lg": 24,
      "xl": 32
    }
  }
}
```

## 시각적 분석 체크리스트

### 컬럼 정렬 확인

```
요소별 컬럼 점유 확인:

□ 전체 너비 요소    → 12컬럼 (12/12)
□ 절반 너비 요소    → 6컬럼 (6/12)
□ 1/3 너비 요소     → 4컬럼 (4/12)
□ 1/4 너비 요소     → 3컬럼 (3/12)
□ 사이드바          → 3-4컬럼
□ 메인 콘텐츠       → 8-9컬럼
```

### 수직 간격 확인

```
기준선 격자와 대조:

□ 섹션 상단 패딩    → __px (8의 배수?)
□ 섹션 하단 패딩    → __px
□ 요소 간 간격      → __px
□ 텍스트 줄간격     → __px
□ 카드 내부 패딩    → __px
```

### 정렬 불일치 해석

```
격자와 맞지 않는 경우:

1. 의도적 예외
   → 비대칭 레이아웃
   → 예술적 오프셋
   
2. 시각 보정
   → optical alignment
   → 아이콘 정렬 보정
   
3. 구현 오류
   → 하드코딩된 값
   → 반응형 미처리
```

## MUI 테마 변환

### 분석 결과 → MUI 토큰

```typescript
// 분석 결과
{
  "columns": 12,
  "gutter": 24,
  "container_width": 1200,
  "base_unit": 8
}

// MUI 테마 변환
const theme = createTheme({
  spacing: 8, // base_unit
  
  breakpoints: {
    values: {
      xs: 0,
      sm: 600,
      md: 900,
      lg: 1200,   // container_width
      xl: 1536,
    },
  },
  
  components: {
    MuiContainer: {
      defaultProps: {
        maxWidth: 'lg',
      },
      styleOverrides: {
        root: {
          paddingLeft: 24,  // gutter
          paddingRight: 24,
        },
      },
    },
  },
});
```

## CRITICAL: 격자 분석 원칙

1. **항상 격자 오버레이부터**
   - 눈대중 X → 격자 대조 O
   
2. **8px 기반 정규화**
   - 7px → 8px, 25px → 24px로 정규화
   
3. **반복 패턴 우선**
   - 예외적 값보다 반복되는 값이 진짜 토큰
   
4. **반응형 별도 분석**
   - Desktop/Tablet/Mobile 각각 격자 분석
   
5. **시각 보정 인식**
   - 1-2px 차이는 optical adjustment일 수 있음
