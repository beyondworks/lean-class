# 인트라넷 스타일 (Lean-AX Intranet DS)

목표: **자 대고 맞춘 듯 동일하게.** 값을 발명하지 말고 **정본 스펙에서 가져온다.**

## 정본 위치 (먼저 읽어라)

스펙 문서는 **이 스킬 폴더 안에** 들어 있다. 값을 발명하지 말고 여기서 가져온다.

```
~/.claude/skills/intranet-style/reference/
  README.md            ← 진입점 + 정규화 결정(혼재 값의 정본) + 기업 배포 절차
  01-tokens.md         ← 색·radius·타이포·간격 토큰 원값, 테마 33종
  02-primitives.md     ← UI 프리미티브 27종 전수(정확한 클래스·variant·상태)
  03-shell-layout.md   ← 앱 셸(사이드바·헤더·콘텐츠·2패널·반응형) + 이식 체크리스트
  04-page-templates.md ← 페이지 6유형 스켈레톤 + 반복 패턴 20종 + do/don't
```

이 문서군은 **살아 있는 인트라넷 코드에서 값을 그대로 추출한 것**이다(추출 시점 스냅샷).
배포판에는 인트라넷 앱 코드가 포함되지 않으므로, **여기서는 이 문서가 정본이다.**
문서에 **"미확인"**으로 적힌 항목은 사실처럼 단정하지 말고 그대로 미확인으로 다룬다.

## 작업 순서

1. **화면 유형 결정** → `04-page-templates.md`에서 해당 유형(대시보드/2패널/목록·테이블/보드/폼·설정/리포트·차트) 스켈레톤을 **복붙**한다.
2. **프리미티브는 `02-primitives.md`의 정확한 클래스로.** 높이·radius·패딩을 임의로 정하지 않는다.
3. **셸이 필요하면** `03-shell-layout.md` 골격(사이드바 폭·헤더 높이·콘텐츠 패딩·2패널 비율)을 그대로.
4. **색·간격은 토큰만.** 하드코딩 색 금지.
5. 완료 후 **재현 체크리스트**로 자기검수(아래).

## 절대 지키는 것 (이걸 놓치면 "비슷한데 다른" 화면이 된다)

1. **컨트롤 기본 높이 `h-8`** (shadcn 기본 `h-9` 아님).
2. **입력 필드는 "채워진" 스타일**: `rounded-2xl h-8 border-transparent bg-input/50` (윤곽선 필드 아님).
3. **표면 경계는 `border`가 아니라 `ring-1 ring-foreground/5`** (전경색 알파 — 테마 33종이라 고정 테두리색을 못 씀).
4. **radius는 스케일로.** 전역 `--radius: 0.625rem` 하나에서 7단계 파생(sm 0.6× ~ 4xl 2.6×). 임의 px 금지.
   - `rounded-2xl`(16px)가 규약이라 **높이 32px 이하 요소는 자연히 pill**이 된다 — 의도된 디자인.
5. **색 값은 `:root`/`.dark` 2층에만.** `--color-*`는 전부 `var()` 별칭. 하드코딩 색(`bg-red-500` 등)은 테마를 깨뜨린다.
6. **Dialog/AlertDialog는 `grid` + `[&>*]:min-w-0` 안전망 필수** — 빼면 긴 URL·와이드 콘텐츠에서 레이아웃이 넘친다.

## 정규화된 정본 값 (코드가 혼재해도 신규는 이것)

| 항목 | 정본 |
|---|---|
| 페이지 루트 컨테이너 | `<div className="space-y-4">` |
| focus 링 | `ring-3 ring-ring/30` |
| 알림/카운트 뱃지 | `h-4 min-w-4 text-[10px] bg-destructive` |
| 다이얼로그 최대 높이 | `max-h-[88vh]` |
| 말줄임표 | `…` (U+2026) |
| 속성 행 라벨 폭 | `w-28` |

## 기업 배포 (디자인 동일 · 기능 커스텀)

1. **골격 이식** — `globals.css` + `components/ui/*` + 셸 복사 (`03-shell-layout.md` 부록 A 체크리스트).
2. **브랜드 테마 주입** — `:root`/`.dark` **2층의 색 토큰만** 기업 브랜드로 교체. radius는 `--radius` **하나만** 조정하면 7단계가 함께 움직인다.
3. **화면** — 6유형 템플릿에서 골라 **기능만** 기업 요구로 교체.
4. npm 의존이 아니라 **복사**(shadcn 철학). 정본 갱신 시 선택적으로 재복사.

## 재현 체크리스트 (제출 전 자기검수)

- [ ] 컨트롤 높이 `h-8` 기본
- [ ] 입력 필드가 채워진 스타일(`bg-input/50 border-transparent rounded-2xl`)
- [ ] 표면 경계가 `ring-1 ring-foreground/5`
- [ ] 색이 전부 토큰 (하드코딩 색 0개)
- [ ] radius가 스케일 값
- [ ] 다이얼로그에 `[&>*]:min-w-0` 살아있음
- [ ] focus 링 `ring-3 ring-ring/30`
- [ ] 아이콘 크기 관례(`size-3.5`/`size-4`)
- [ ] 빈 상태·로딩·에러 화면을 템플릿대로 포함

## 하지 말 것

- 스펙에 없는 값을 **추정해서 채우지 마라.** 없으면 정본 문서/코드를 열어 확인한다.
- 색·크기를 "비슷하게" 맞추지 마라 — 토큰·클래스를 **그대로** 쓴다.
- 정본 문서에 **"미확인"**으로 적힌 항목을 사실처럼 단정하지 마라.
