# 09-output-styles — 한국어 출력 스타일

## 이게 뭔가

Claude가 **한국어를 문법적으로 온전하게 쓰도록** 시스템 프롬프트 층위에서 규율하는 출력 스타일입니다. 스킬처럼 호출해서 쓰는 것이 아니라, 켜 두면 모든 답변에 상시 적용됩니다.

원본: [snflkd/fluent-korean](https://github.com/snflkd/fluent-korean) (MIT)

## 왜 필요한가

코딩 에이전트는 토큰을 아끼려고 문장을 짧게 쓰도록 설정돼 있는데, 이것이 한국어에서는 다른 결과를 냅니다. 영어는 관사를 떨어뜨려도 문장이 읽히지만, **한국어는 조사와 어미가 격 관계를 표시하는 유일한 장치**입니다. 그것을 떨어뜨리면 의미 관계가 사라집니다.

```
전  지출 비용 추론 용도의 토큰 카운트 함수의 오류 상황에서
후  지출한 비용을 추론하는 토큰 카운트 함수에 오류가 발생하면
```

## 두 가지 판

| 파일 | 언제 쓰나 |
|---|---|
| `fluent-korean` | 코드 작업 (기본값). Claude Code의 코딩 지침을 유지 |
| `fluent-korean-not-coding` | 코드를 직접 고치지 않는 작업 — 기획·문서·상담·리서치 |

## 설치

```bash
bash 09-output-styles/install-output-styles.sh
```

원본 레포에서 받아와 `~/.claude/output-styles/`에 두고, `settings.json`의 기본값을 설정합니다. **새 세션 또는 `/clear` 후에 적용됩니다** — 출력 스타일은 시스템 프롬프트에 들어가기 때문입니다.

판을 바꾸려면 `~/.claude/settings.json`의 `outputStyle` 값을 바꾸거나, 대화형 터미널에서 `/config`로 고릅니다. 프로젝트별로 다르게 쓰려면 그 프로젝트의 `.claude/settings.local.json`에 넣으면 전역값을 덮어씁니다.

## 덧붙인 조항 2개

설치 스크립트가 원본 말미에 두 문장을 더합니다. 둘 다 원저자 README가 '세부 동작' 블록으로 제공하는 문장입니다.

1. **전용 지침이 있는 산출물은 면제** — 화법 스킬이나 대본 지침처럼 자체 문체 규칙이 걸린 작업에서 스타일이 충돌하지 않게 합니다.
2. **저빈도 어휘 억제** — 사전에는 있지만 통용되지 않는 단어를 쓰지 않게 합니다.

## 알아 둘 것

- **토큰을 조금 더 씁니다.** 생략된 조사·어미를 복원하므로 한국어 문장이 소폭 길어집니다. 헤더와 목록은 규칙에서 면제라 구조화된 짧은 보고는 그대로 유지됩니다.
- **컨텍스트 압박이 크면 잘 지켜지지 않습니다.** 원저자도 명시한 한계입니다. 긴 세션 후반에 문체가 흐트러지면 지침을 고치기보다 검증 단계를 두는 쪽이 낫습니다.
- 인용·코드·코드 주석에는 적용되지 않습니다.
